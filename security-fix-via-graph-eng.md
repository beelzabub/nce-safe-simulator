**Method:** graph/fan-out agentic triage — 4 triage agents (by finding class) → 4 adversarial skeptic agents that re-read the code and tried to *disprove* each finding → merge & rank. 8 agents, 0 errors.  
**Rule:** every finding below carries a source link (scanner rule doc + GitLab vulnerability) and the detection date.

1. **`helm/nce-safe-simulator/templates/deployment.yaml`** — add a pod + container `securityContext` (`allowPrivilegeEscalation: false`, `runAsNonRoot: true`, `runAsUser: >=10000`, `readOnlyRootFilesystem: true` + `/tmp` emptyDir, `seccompProfile: RuntimeDefault`, `capabilities.drop: [ALL]`), set `automountServiceAccountToken: false`, and pin `image.tag`. **Clears ~10 findings.**
